## Master Cross-Link Map

### ZK Proofs (Foundations) connects to:
- Chains > L2s → ZK rollups (zkSync, StarkNet, Scroll)
- Privacy → Zcash, Aztec, shielded transactions
- Identity → ZK credentials, proof of personhood
- Interoperability → ZK light client bridges
- Frontier > AI → ZKML (proving ML inference)
- DeFi → Private DeFi (dark pools)

### Stablecoins (DeFi) connects to:
- Payments (Applications) → the payment rail
- Regulation → MiCA, GENIUS Act, securities law
- Token Economics → reserve models, yield-bearing stablecoins
- Chains → Tron (50% USDT), Ethereum, Solana
- RWA → RWA-backed stablecoins (USDY)

### MEV connects to:
- DeFi > DEXs → sandwich attacks on AMMs
- DeFi > Lending → liquidation MEV
- Foundations > Consensus → block production
- Chains > L2s → sequencer-extractable value
- Infrastructure → Flashbots, MEV-Boost, private RPCs
- Interoperability → cross-domain MEV

### Oracles (Infrastructure) connects to:
- DeFi → price feeds for all protocols
- Security → oracle manipulation attacks
- RWA → real-world data on-chain
- Insurance → parametric insurance triggers
- Derivatives → settlement prices

### Account Abstraction (Frontier/Infrastructure) connects to:
- Wallets → smart wallets, passkeys, gasless
- Identity → programmable identity
- MEV → bundler as MEV actor
- Chains > L2s → native AA (zkSync, StarkNet)
- DeFi → gasless DeFi, session keys for trading

### Restaking (DeFi) connects to:
- Security → shared security model
- Infrastructure → EigenDA, AVS services
- Token Economics → restaking yield, LRT tokens
- Chains → securing new chains/services
- Governance → restaking governance

### Token Economics connects to (everything):
- Every chain → tokenomics of each L1/L2
- DeFi → LP rewards, yield farming incentives
- Governance → voting power, delegation
- Applications > Gaming → play-to-earn models
- DePIN → infrastructure incentive flywheels
- Memecoins → bonding curves, launch mechanics

### Privacy connects to:
- Identity → selective disclosure, stealth addresses
- DeFi → private DeFi, dark pools
- Regulation → compliance vs privacy tension
- Foundations → ZK, FHE, MPC primitives
- AI → private AI inference

## Visual Representation Ideas

### Main Canvas Edge Style
- **Technical dependency**: solid line (e.g., DeFi → Chains)
- **Cross-cutting concern**: dashed line (e.g., Regulation → DeFi, Privacy → Identity)
- **Innovation frontier**: dotted line with glow (e.g., AI → DeFi, FHE → Privacy)

### Color Coding for Edge Types
- Blue: technical stack dependency
- Orange: security/risk relationship
- Green: value flow (tokens, revenue)
- Purple: conceptual relationship
